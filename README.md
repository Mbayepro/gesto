# Fcfa Sales Ace

Crée une application web responsive de gestion commerciale et de facturation destinée à un vendeur de matériels électroniques et électroménagers au Sénégal.



IMPORTANT :

- Je veux une première maquette réellement fonctionnelle et navigable, pas seulement une landing page.

- L'application doit être pensée d'abord pour smartphone, mais fonctionner parfaitement sur tablette et ordinateur.

- Utilise des données fictives réalistes pour démontrer le fonctionnement.

- Interface moderne, professionnelle, simple et très rapide à utiliser.

- Langue principale : français.

- Devise : FCFA.

- Ne surcharge pas l'interface.

- Design premium mais accessible à un petit commerçant.
